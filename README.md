
# Smart Ultrasonic Assistive Walking Stick

**Individual Engineering Project | Class 10**

## 1. Project Overview
This project is an Arduino-based assistive walking stick designed to help visually impaired people detect nearby obstacles through ultrasonic sensing and audible alerts.

## 2. Motivation
The idea came from observing elderly people in my village experiencing difficulties while walking at night. I wanted to explore how simple electronics and programming could help address this problem.

## 3. Components Used
- Arduino board
- Ultrasonic sensor
- Buzzer
- Connecting wires
- Walking stick structure

## 4. Working Principle
1. The ultrasonic sensor detects nearby obstacles.
2. The Arduino processes the sensor readings.
3. When an obstacle is detected, the buzzer produces an audible alert.
